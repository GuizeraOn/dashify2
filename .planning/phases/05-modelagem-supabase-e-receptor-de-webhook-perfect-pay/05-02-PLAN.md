<task type="auto">
  <name>Task 2: Implementar endpoint POST /api/webhooks/perfectpay</name>
  <files>app/api/webhooks/perfectpay/route.ts, .env.example</files>
  <read_first>lib/parsers/perfectpay.ts, lib/supabase.ts</read_first>
  <action>
1. Adicionar `PERFECTPAY_WEBHOOK_TOKEN="seu_token_aqui"` no `.env.example`.
2. Criar `app/api/webhooks/perfectpay/route.ts`:
   - Método `POST(request: NextRequest)`:
     - Fazer parse de `body = await request.json()`.
     - Validar token: se `process.env.PERFECTPAY_WEBHOOK_TOKEN` estiver configurado e `body?.token !== process.env.PERFECTPAY_WEBHOOK_TOKEN`, retornar `NextResponse.json({ error: 'Unauthorized: invalid token' }, { status: 401 })`.
     - Chamar `parsedSale = parsePerfectPayPayload(body)`.
     - Se `!parsedSale.code`, retornar `NextResponse.json({ error: 'Missing sale code' }, { status: 400 })`.
     - Obter cliente Supabase com `getSupabaseAdmin()`.
     - Executar upsert na tabela `sales`:
       ```ts
       const { error } = await getSupabaseAdmin()
         .from('sales')
         .upsert(parsedSale, { onConflict: 'code' });
       ```
     - Se houver erro de banco, logar e responder com status 500 para permitir retentativa se for erro temporário de banco.
     - Se sucesso, retornar `NextResponse.json({ success: true, code: parsedSale.code })`.
  </action>
  <verify>npx tsc --noEmit</verify>
  <acceptance_criteria>
    - app/api/webhooks/perfectpay/route.ts existe e exporta POST
    - Validação de token confere com PERFECTPAY_WEBHOOK_TOKEN
    - Executa upsert com onConflict: 'code'
    - Retorna HTTP 200 com JSON { success: true }
  </acceptance_criteria>
  <done>Endpoint receptor implementado, validado e integrado com o Supabase.</done>
</task>
